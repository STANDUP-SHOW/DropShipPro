# Logos des plateformes

Ces fichiers servent à **identifier** chaque place de marché dans l'annuaire et
les pages de mode d'emploi. C'est un usage nominatif : on cite la marque pour
désigner le service, sans laisser croire à un partenariat ni à une approbation.

Trois règles, tenues :

- **aucun logo de concurrent direct** — le paquet d'origine en contenait un, il a
  été écarté ;
- **aucune retouche** : un logo se reproduit tel que la marque le publie ;
- **aucune mise en avant commerciale** : les plateformes sont présentées à
  égalité, dans l'ordre alphabétique de leur catégorie.

Pour les pages publiques destinées au référencement, la source la plus sûre
reste l'espace presse de chaque marque, qui précise les usages autorisés.
Remplacer un fichier ici par celui du kit officiel ne demande qu'à garder le
même nom.

Les fichiers dont le nom ne désignait aucune marque (`default--12-.svg`,
drapeaux de langue, éléments d'interface) ont été retirés : ils n'identifient
rien.
